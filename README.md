# DemBase

Sistema pessoal para controle de finanças e planejamento financeiro.

## Como rodar

1. Ative o ambiente virtual:

```powershell
.\venv\Scripts\Activate.ps1
```

2. Instale as depend?ncias:

```powershell
pip install -r requirements.txt
```

3. Inicie o app:

```powershell
python app.py
```

## Tecnologias

- **Python** ? linguagem principal
- **Flet** ? interface gráfica multiplataforma (Windows, Mac, Linux, Web e Mobile)
